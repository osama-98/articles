ترجمة الـEnums في Laravel

توقّف عن كتابة النصوص داخل كتل match. laravel-enum-translatable تمنح الـenums في PHP ترجمة كاملة، وarray helpers، ومقارنة آمنة — كلها عبر traits

composer require osama-98/laravel-enum-translatable PHP 8.2+ Laravel 11+

الـenums هي المكان الطبيعي لمجموعات الـcases الثابتة — OrderStatus وCourseStatus وRole. لكن ما إن يتحدّث تطبيقك أكثر من لغة حتى يظهر سؤال: أين يعيش النص الذي يقرأه المستخدم؟

الحل المعتاد match داخل الـenum، أو استخدام __() في الـBlade

لماذا كتابة النص داخل الكود

match داخل الـenum يربط الـdata type بلغة واحدة.

طباعة النص مباشرةً على الـenum قد يعمل بشكل جيد عندما يكون النظام بلغة واحدة ولكن عند اضافة لغة جديدة يصبح الامر معقد.

قبل
OrderStatusEnum.php 
<?php

enum OrderStatusEnum: string
{
    case PENDING   = 'pending';
    case SHIPPED   = 'shipped';
    case DELIVERED = 'delivered';

    public function label(): string
    {
        return match($this) {
            self::PENDING   => 'Pending',   // English only —
            self::SHIPPED   => 'Shipped',   // adding Arabic means
            self::DELIVERED => 'Delivered', // rewriting this method
        };
    }
}

المشكلة: اصبح الـenum يملك الترجمة. كل لغة، وكل تعديل صياغة، وكل شكل لاستجابة الـAPI يفرض تعديلاً على ملف يُفترض أن يصف الـcases فقط.

1 الخطوات

أمر Composer واحد، ثم وَلِّد Enum عبر مساعد artisan.

terminal 
# requires PHP 8.2+ and Laravel 11+
composer require osama-98/laravel-enum-translatable

# optional: scaffold a new enum class
php artisan make:enum OrderStatus

طبّق الـtrait EnumTranslatable وعرّف الحالات. لا حاجة لدالة label() — النصوص تأتي من ملف اللغة.

app/Enums/OrderStatusEnum.php 
<?php

use Osama\LaravelEnums\Traits\EnumTranslatable;

enum OrderStatusEnum: string
{
    use EnumTranslatable;

    case PENDING   = 'pending';
    case SHIPPED   = 'shipped';
    case DELIVERED = 'delivered';
}

2 ضع النصوص في lang/

اسم الـenum class يتحوّل إلى مفتاح. كل لغة مجرّد ملف إضافي.

النصوص مفهرسة بنسخة snake_case بصيغة الجمع من اسم الـenum — OrderStatusEnum ← order_statuses. أضف ملفاً لكل لغة وتكتمل الترجمة.

lang/en/enums.php 
<?php

return [
    'order_statuses' => [
        'pending'   => 'Pending',
        'shipped'   => 'Shipped',
        'delivered' => 'Delivered',
    ],
];
lang/ar/enums.php 
<?php

return [
    'order_statuses' => [
        'pending'   => 'قيد الانتظار',
        'shipped'   => 'تم الشحن',
        'delivered' => 'تم التوصيل',
    ],
];

3 اقرأ النص

trans() تستخدم اللغة الحالية؛ مرّر لغة لتجاوزها؛ وallTrans() تُرجِع كل اللغات دفعة واحدة.

anywhere — controller, Blade, resource 
$status = OrderStatusEnum::PENDING;

$status->trans();              // 'Pending'  (uses app()->getLocale())
$status->trans('ar');          // 'قيد الانتظار'

// optional context — points at a sibling key for a longer string
$status->trans(context: 'description');
// 'This order is awaiting processing.'

// every supported locale in one call
$status->allTrans();
// ['en' => 'Pending', 'ar' => 'قيد الانتظار']

4 أرسلها للواجهة الأمامية

حوّل الـenum كاملاً إلى value / name مترجمة — مثالية لقائمة dropdown أو استجابة JSON.

قائمة الطعام: الـselect يحتاج القيمة المخزَّنة والكلمة التي يقرأها المستخدم معاً. هذه الـmethods تسلّمك الاثنتين، مترجمتَين، باستدعاء واحد.

building a select / API payload 
// array of ['value' => ..., 'name' => ...] pairs
OrderStatusEnum::toArrayTrans('ar');
// [
//   ['value' => 'pending',   'name' => 'قيد الانتظار'],
//   ['value' => 'shipped',   'name' => 'تم الشحن'],
//   ['value' => 'delivered', 'name' => 'تم التوصيل'],
// ]

// same data, as a Laravel Collection for fluent chaining
OrderStatusEnum::toTransCollection()->pluck('name', 'value');

// a single case as a structured pair
$status->object();
// ['value' => 'pending', 'name' => 'Pending']

5 اختر الـtrait المناسب

three levels 
// 1. comparison + safe casting only
use EnumWrappable;

// 2. + array helpers (names, values, filtering, random)
use EnumArrayable;

// 3. + full translation (everything above, plus trans/allTrans)
use EnumTranslatable;

6 تحويل ومقارنة آمنان

حوّل المدخلات غير الموثوقة إلى Enum، وقارن دون استخدام ->value في كل مكان.

wrap() تقوم هذه الدالة بالتحقق من وجود القيمة بالـ enum وفي حال العثور عليها تقوم بارجاع object من هذا الـ enum اما في حال عدم العثور عليها فتقوم بارجاع null

EnumWrappable helpers 
// cast a raw string/value into the enum — safely
OrderStatusEnum::wrap('pending');          // OrderStatusEnum::PENDING
OrderStatusEnum::wrap('unknown');          // null (strict: throws)

// readable comparisons — no manual ->value plumbing
$status->is('pending');                 // true
$status->isNot('shipped');              // true
$status->isAny(['pending', 'shipped']);  // true

لماذا يفيد: بيانات الـrequest وquery strings وwebhook payloads تتحوّل إلى enums — وبقيّة الكود يعمل بالـtypes لا بالـstrings

7 الـarray helpers

querying the case set 
OrderStatusEnum::names();    // ['PENDING', 'SHIPPED', 'DELIVERED']
OrderStatusEnum::values();   // ['pending', 'shipped', 'delivered']

// filter the set by value
OrderStatusEnum::only(['pending', 'shipped']);
OrderStatusEnum::except(['delivered']);

// wildcard matching
OrderStatusEnum::matching('ship*');     // [SHIPPED]
OrderStatusEnum::contains('end');       // [PENDING]

// random pick — handy for seeders & factories
OrderStatusEnum::randomCase(except: OrderStatusEnum::DELIVERED);

8 الإعداد (اختياري)

terminal 
php artisan vendor:publish --tag="laravel-enums-config"

خيارات أساسية في config/laravel-enums.php:

  • supported_locales — اللغات التي يمرّ عليها allTrans().
  • modular_enabled — قراءة الترجمات من الـmodules (مثل nWidart/laravel-modules).
  • namespace_resolver — منطق مخصّص لتحديد الـnamespace الخاص بالترجمة.
