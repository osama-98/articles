دليل معايير ال PSR

شرح مبسّط لجميع معايير PHP Standards Recommendations مع أمثلة عملية، مرتّبة حسب الحالة.

● معتمد (Accepted) ● مهجور/قديم (Deprecated) ● مسوّدة (Draft) ● متروك (Abandoned)

المعايير المعتمدة 14

هذه هي المعايير الفعّالة والموصى باستخدامها في المشاريع الحديثة.

PSR-1

المعيار الأساسي للكود

معتمد

قواعد أساسية: تسمية الكلاسات بأسلوب StudlyCaps، والدوال بـ camelCase، والثوابت بأحرف كبيرة.

basics.php 
class UserProfile {        // StudlyCaps
    const MAX_AGE = 120;     // UPPER_CASE
    public function getName() {} // camelCase
}
PSR-3

واجهة التسجيل (Logger)

معتمد

واجهة موحّدة لكتابة سجلات الأحداث والأخطاء بمستويات مختلفة، بحيث يمكنك تبديل مكتبة التسجيل دون تغيير كودك.

logger.php 
$logger->info('تم تسجيل دخول المستخدم');
$logger->error('فشل الاتصال بقاعدة البيانات');
$logger->warning('مساحة التخزين منخفضة');
PSR-4

التحميل التلقائي (Autoloading)

معتمد

يربط اسم الكلاس بمسار الملف تلقائياً، فلا تحتاج require يدوياً. هذا أساس عمل Composer.

autoload.php 
// الكلاس:
namespace App\Models;
class User {}

// المسار المتوقّع للملف:
// src/Models/User.php
PSR-6

واجهة التخزين المؤقت (Cache)

معتمد

نظام تخزين مؤقت متقدّم يعتمد على «مجمّع» Pool و«عناصر» Item، يمنحك تحكّماً دقيقاً.

cache-pool.php 
$item = $pool->getItem('user_42');
if (!$item->isHit()) {
    $item->set($userData);
    $pool->save($item);
}
PSR-7

رسائل HTTP

معتمد

يوحّد تمثيل طلبات واستجابات HTTP ككائنات. الرسائل غير قابلة للتغيير (immutable)، ويُستخدم بكثرة في الـ APIs.

http-message.php 
$method = $request->getMethod();      // "GET"
$path   = $request->getUri()->getPath();
$code   = $response->getStatusCode();  // 200
PSR-11

واجهة الحاوية (Container)

معتمد

واجهة موحّدة لحاويات حقن التبعيات (DI Container) لجلب الخدمات والكائنات.

container.php 
if ($container->has('mailer')) {
    $mailer = $container->get('mailer');
}
PSR-12

نمط الكود الموسّع

معتمد

تفاصيل التنسيق الكاملة: ٤ مسافات للإزاحة، أماكن الأقواس، المسافات. يحل محل PSR-2 القديم.

style.php 
class User
{
    public function getName(): string
    {
        return $this->name;
    }
}
PSR-13

روابط الوسائط (Hypermedia Links)

معتمد

طريقة موحّدة لتمثيل الروابط في الـ APIs (مثل HATEOAS)، يحمل كل رابط عنوانه وعلاقته.

links.php 
$link->getHref();  // "/users/42"
$link->getRel();   // "self" أو "next"
PSR-14

موزّع الأحداث (Event Dispatcher)

معتمد

نظام موحّد للأحداث: تُطلق حدثاً، فتستجيب له «المستمعات» (Listeners) المسجّلة.

events.php 
// إطلاق حدث بعد تسجيل مستخدم جديد
$dispatcher->dispatch(new UserRegistered($user));
PSR-15

معالِجات HTTP (Middleware)

معتمد

يوحّد كتابة الطبقات الوسيطة (Middleware) التي تعالج الطلب قبل وصوله للوجهة (مثل التحقق من المصادقة).

middleware.php 
public function process($request, $handler)
{
    // تحقّق ثم مرّر الطلب للطبقة التالية
    return $handler->handle($request);
}
PSR-16

التخزين المؤقت المبسّط (Simple Cache)

معتمد

نسخة أبسط من PSR-6 بواجهة مباشرة get/set، مناسبة للاستخدامات اليومية.

simple-cache.php 
$cache->set('key', $value, 3600); // لمدة ساعة
$value = $cache->get('key', $default);
PSR-17

مصانع HTTP (Factories)

معتمد

واجهات موحّدة لإنشاء كائنات PSR-7 (طلبات، استجابات، عناوين) بطريقة معيارية.

factories.php 
$request = $factory->createRequest(
    'GET', 'https://api.example.com'
);
PSR-18

عميل HTTP (Client)

معتمد

واجهة موحّدة لإرسال طلبات HTTP واستقبال الردود، فيمكنك تبديل مكتبة الاتصال دون تغيير كودك.

http-client.php 
$response = $client->sendRequest($request);
echo $response->getStatusCode(); // 200
PSR-20

الساعة (Clock)

معتمد

واجهة موحّدة للحصول على الوقت الحالي، ما يسهّل اختبار الكود بتزييف الوقت (mocking).

clock.php 
$now = $clock->now(); // DateTimeImmutable

معايير قديمة / مهجورة 2

كانت معتمدة سابقاً لكنها استُبدلت بمعايير أحدث. لا تُستخدم في المشاريع الجديدة.

PSR-0

التحميل التلقائي (القديم)

مهجور

أول معيار للتحميل التلقائي، اعتمد على الشرطة السفلية في أسماء الكلاسات. استُبدل بـ PSR-4 الأبسط والأنظف.

PSR-2

دليل نمط الكود (القديم)

مهجور

المعيار الأصلي لتنسيق الكود. استُبدل بـ PSR-12 الذي وسّعه وأضاف قواعد لميزات PHP الحديثة.

معايير قيد الإعداد (مسوّدات) 4

قيد المناقشة والتطوير، وقد تتغيّر قبل اعتمادها. ليست جاهزة للاعتماد عليها بعد.

PSR-5

معيار PHPDoc

مسوّدة

توحيد طريقة كتابة تعليقات التوثيق (DocBlocks) فوق الدوال والكلاسات.

phpdoc.php 
/**
 * @param  int   $id
 * @return User
 */
PSR-19

وسوم PHPDoc

مسوّدة

مكمّل لـ PSR-5، يحدّد قائمة الوسوم القياسية مثل @param و @return و @throws.

PSR-21

التدويل (Internationalization)

مسوّدة

واجهة موحّدة للترجمة وتعدّد اللغات والصيغ المحلية (التواريخ والأرقام والعملات).

PSR-22

تتبّع التطبيقات (Tracing)

مسوّدة

واجهة موحّدة لتتبّع أداء التطبيق ومراقبته (observability) عبر مكوّناته المختلفة.

معايير متروكة 3

اقتُرحت لكنها لم تكتمل أو لم تحظَ بالموافقة، وتوقّف العمل عليها.

PSR-8

واجهة العناق (Huggable)

متروك

اقتراح طريف (مزحة) لواجهة تجعل الكائنات «قابلة للعناق». لم يكن جدّياً ولم يُعتمد. 🙂

PSR-9

الإفصاح عن الثغرات الأمنية

متروك

اقتراح لتوحيد طريقة الإعلان عن الثغرات الأمنية في المشاريع. لم يُكمَل.

PSR-10

عملية الإبلاغ عن الثغرات

متروك

مكمّل لـ PSR-9، يحدّد كيفية استقبال بلاغات الثغرات ومعالجتها. لم يُكمَل أيضاً.

باختصار

إجمالاً تم ترقيم المعايير من PSR-0 حتى PSR-22: منها ١٤ معتمداً وفعّالاً، و٢ مهجوران (استُبدلا بأحدث)، و٤ مسوّدات قيد العمل، و٣ متروكة.

ال PSR ليست قواعد إجبارية يفرضها مترجم PHP، بل اتفاقيات يلتزم بها المجتمع طوعاً — والالتزام بها يجعل مشروعك احترافياً ومتوافقاً مع المكتبات والفريموركات الكبيرة.
